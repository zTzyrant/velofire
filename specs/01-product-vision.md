# Product Vision

## Tujuan

Velofire adalah API client modern cross-platform seperti Postman, tetapi lebih ringan, offline-first, Git-friendly, privacy-focused, AI-assisted, dan terasa native berkat core berbasis Rust.

Produk harus memprioritaskan workflow developer harian: cepat dibuka, cepat mengirim request, mudah mengelola koleksi, nyaman dipakai keyboard, dan tidak bergantung cloud untuk fungsi inti.

## Target Platform

Target utama:

- Windows
- macOS
- Linux

Target masa depan:

- Android
- iOS

## Filosofi Produk

- Fast startup.
- Minimal RAM usage.
- Native networking.
- Local-first workflow.
- Clean and compact UX.
- Developer productivity.
- Offline-first untuk fungsi inti.
- Git-native untuk koleksi dan konfigurasi.

## Posisi Produk

Velofire harus terasa seperti developer tool native, bukan web app berat yang dibungkus desktop shell. Benchmark pengalaman adalah alat produktivitas seperti VSCode, Linear, dan API clients modern, dengan fokus lebih besar pada density, keyboard flow, dan reliable local data.

## Keunggulan Kompetitif

Developer mungkin beralih karena:

- Lebih cepat dari Postman.
- Penggunaan memori lebih kecil.
- Bisa digunakan penuh secara offline.
- Koleksi mudah di-diff dan dikolaborasikan lewat Git.
- UI lebih bersih dan padat.
- Pengalaman desktop terasa native.
- Workflow keyboard lebih baik.

## Prinsip Prioritas

Jangan membangun semua fitur sekaligus. Urutan prioritas produk:

1. Fast request engine.
2. Beautiful and compact UX.
3. Smooth request workflow.
4. Stability.
5. Keyboard productivity.

Fitur besar seperti AI, GraphQL, WebSocket, plugin, sync, dan collaboration harus mengikuti fondasi ini, bukan mendahuluinya.
